# 돈꺼비 — 팀 프로젝트 원본

SSAFY 팀 프로젝트 당시 코드와 변경 이력을 보존하는 저장소입니다. 현재 포트폴리오 설명과 실행 안내는 [MoneyToad-Portfolio](https://github.com/rladbstn1000/MoneyToad-Portfolio)를 참고하세요.

김윤수는 Spring Boot 인증·토큰 관리, 소비 내역·예산 API, 월별·카테고리별 집계, AI 분석 결과 연동을 담당했습니다. 프런트엔드·시각 디자인·AI 분석 서비스를 포함한 전체 서비스는 팀 공동 결과입니다.

[공개 체험판](https://moneytoad-portfolio.pages.dev/)은 브라우저 메모리의 샘플 데이터로 동작합니다. [개선 사례와 담당 범위](https://github.com/rladbstn1000/MoneyToad-Portfolio/blob/main/docs/portfolio/contribution-boundary.md)를 원본 기능과 구분해 확인할 수 있습니다.

원본의 과거 환경값과 운영 문서는 현재 실행용 설정이나 보안 상태를 보증하지 않습니다. 실제 접속정보를 재사용하지 말고 별도로 관리하세요.
